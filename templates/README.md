# Templates

Copy these into a governed project directory (or `~/.tenuo/` for the admin env file).

| File | Destination |
|------|-------------|
| `tenuo.yaml.example` | `./tenuo.yaml` |
| `tenuo.yaml.cloud.example` | merge via `tenuo-claude init --cloud` |
| `tenuo.yaml.advanced.example` | merge via `tenuo-claude init --advanced` |
| `cloud.env.example` | `.state/cloud.env` |
| `admin.env.example` | `~/.tenuo/admin.env` |

Ready-made policies with subagents and MCP: [examples/policies/](../examples/policies/).
